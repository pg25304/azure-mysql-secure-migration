# Project Evidence

This folder contains selected screenshots captured during the secure MySQL migration project.

The evidence demonstrates key stages of the implementation, including:

- Azure networking and VNet configuration
- Site-to-site VPN connectivity
- Private DNS and network validation
- TLS-secured MySQL connectivity
- Azure Database Migration Service execution
- Successful migration completion
- Independent post-migration data verification

Sensitive information such as passwords, private SSH keys and VPN pre-shared keys has been excluded or redacted.
